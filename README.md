# Viva Engage Essentials

Static GitHub Pages site for the five-part Viva Engage Essentials learning experience.

## Files
- `index.html` — page content
- `style.css` — design
- `script.js` — lesson navigation
- `videos/01.mp4` through `videos/05.mp4` — embedded lesson videos

For this test package, the same sample MP4 is used for all five lessons.

## Replace videos later
Keep the filenames `01.mp4`, `02.mp4`, `03.mp4`, `04.mp4`, and `05.mp4`, and replace each file with the finished lesson video.

## GitHub Pages
Upload the contents of this package to the root of the `viva-engage` repository, then go to:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
